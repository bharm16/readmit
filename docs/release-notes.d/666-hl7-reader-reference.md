- The HL7 message reader can use an explicitly selected offline catalog for
  edition-specific segment and field definitions. The reader preserves original
  encoded values separately from decoded text and exposes all eleven metadata
  columns through horizontal scrolling. Missing reference material and source
  coverage gaps remain visible while original-byte inspection stays available.

  Catalogs are built locally from the supplied official HL7 schema/chapter
  sources; controlled reference content is not bundled pending distribution
  approval. Reference metadata does not establish message validation or receiver
  correctness.
