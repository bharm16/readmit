- A case's Findings now opens its latest saved analysis of this exact case
  version as one list — finding, classification and review — with the
  selected finding beside it, or Not analyzed with Analyze (#551). Opening the
  page never analyzes. Analyze uses the one compatible profile directly, asks
  only when several are, and refuses a profile the engine does not evaluate
  over this case; Stop keeps the previous findings and saves nothing. History
  lists earlier analyses newest first and opens one as not current. Analysis
  settings are named, saved as one version, and an imported configuration this
  release does not support stays as imported. Review records Confirm, Dismiss
  or Suppress (with its scope and what it covers) with a required reason as a
  new revision of the analysis's review; Undo decision records another
  revision and history keeps both. View messages shows exactly the finding's
  messages, including ones outside the loaded page, with the way back. Similar
  findings groups the findings of the cases you choose and lists a case it
  could not compare with its reason.
