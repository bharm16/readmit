- A case's Messages open at once as one full-height list of Time, Type, Source
  and Direction, with no index to choose or build first (#549). Type is the
  message's own code and trigger (such as SIU · S13), ACK or Unparsed. Search
  and Filter apply to the list without saving anything and show as removable
  chips; Save view names the applied filter for this project, and views can be
  renamed and removed. Rows you select offer Create test, Send selected and
  Create variant. The message reader shows segments by name, fields with their
  labels and exact paths, and keeps values hidden until Show values; Empty,
  Null and Not present stay distinct, and Filter by this field starts a filter
  from the selected field. Tools → Inspect file opens a file straight into the
  same reader, with Format and Save copy in its menu. Search settings no longer
  ask for an index file name.
