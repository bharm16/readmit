- **Share** on a report in the desktop app is now one flow, Contents →
  Redaction → Preview. Contents lists what the share holds and adds the
  report's messages, attachments or original evidence only when chosen; the
  destination, format and file are set there, and **Encrypt package** writes it
  as an encrypted package under an active encryption control. Redaction applies
  a named disclosure template: the values the report restates are derived from
  the same messages it holds, and title, notes, metadata and anything no rule
  reaches stay **Unresolved** until treated in its own sheet. Preview shows the
  exact output — the PDF's pages, the HTML page, or the text — with every
  unresolved item listed before **Export** or **Send**, and any change withdraws
  it. **Export** on a report opens the same Preview. Completed shares appear in
  the report's History.
- A template that checks derived tests by a run keeps a share holding messages
  blocked until **Run check** has derived the check and its reviewed run
  reproduced the original result; the export then includes the proven derived
  test.
- **Templates**, **Support summary** and **Encrypted packages** are in Reports'
  More menu. A support summary is previewed whole under the project's sharing
  policy and exported once; Help › Diagnostics opens it too. Encrypted packages
  are decrypted to a chosen place and deleted under their declared retention,
  with an override that needs a reason. The earlier privacy, protection and
  export review panels, and their Review ID and Preview ID fields, are gone.
