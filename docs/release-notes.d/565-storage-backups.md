- Settings → Storage now lists the project's backups by project, date and size,
  with the folder backups are kept in and Change (#565). Create backup writes
  a new verified backup there; a damaged, missing or incomplete backup stays
  in the list with its reason. Restore, from a backup's details or a backup
  chosen elsewhere, creates a separate project under a name and location you
  can change, then opens its cases; the current project is never overwritten.
  Verify backup, Show in folder and Delete are in a backup's menu. Recovery
  copies, Archive, Move project, Repair search, Staged update and Delete from
  this computer are separate tasks in the Storage menu, each shown in full
  before its final button. Deleting from this computer uses the verified
  archive and says exactly what remains if it could not remove everything.
