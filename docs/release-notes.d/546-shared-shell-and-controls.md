- The desktop window has one shared frame: a 13rem sidebar (Projects, the open project's switcher and Cases, Tests, Runs, Environments and Reports, then Tools, Settings and Help) that becomes a labelled icon rail in a narrow window with the project switcher in the page header, and no status footer. A running operation shows in the sidebar with Stop when it can stop; Escape no longer cancels anything and only closes the topmost dialog or menu. Tests opens Tests and Suites with a separate Library for Checks, Profiles and Scenarios; Runs, Reports and Tools open their tasks from actions with a Back button that restores where you were. The command palette (⌘K / Ctrl+K) ranks results, lists only what applies, and opens each action's own flow. The message list draws only its visible rows at any window or text size; details beside it open at a remembered width and are shown on their own when the list would be too narrow. Settings › General shows its values with an Edit sheet. Field states read Present, Empty, Null and Not present, a permission refusal reads Access denied, and every colour is a system colour.
