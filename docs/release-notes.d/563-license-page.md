- Settings › License is one page: this computer's license as read-only values
  (status, plan, licensed user, device, expiry) with the one action its state
  calls for — Activate, Renew or Resolve clock — and Export license,
  Deactivate, Administrator setup and Details under More. Activating and
  renewing are one sheet (License, Assignment, Review) that installs only on
  its final action and only the exact file or pasted text that was verified;
  a renewal keeps this device's assignment and says Install renewal. A clock
  set back is shown on the license and resolved there once the clock is
  correct. A task refused for want of a license opens this flow and returns
  to the task afterwards, which is then taken again. Administrator setup is
  its own page with a sheet per task — activation folder, create, renew,
  release, export, clock recovery and account portal — and the account
  portal is kept only when saved. Manage account appears only once an
  operator configured the portal.
