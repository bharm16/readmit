- Settings › Runners lists the project's named runners with the status an actual
  admission or read established, dated, and Not checked until one has. Add runner
  ends in a real admission, or exports the setup for another host without claiming
  it installed; Configuration, Access, Capacity, Recovery, Update and Run job are
  each their own task.
- Schedules are now created, edited, enabled, paused and deleted through the hub's
  schedule service (`readmit-hub serve -schedules`), which acknowledges every change:
  daily, weekday or selected-day recurrences in a named time zone, reviewed with
  their exact pinned versions and next three runs. A change the hub has not
  acknowledged stays Pending. Missed windows, skipped daylight-saving minutes and
  changed inputs are recorded, never caught up or approved automatically.
- A suite's Set up CI generates the configuration for its exact version in one
  sheet; Runs › Import CI results and a suite's Gate results read retained CI
  evidence.
