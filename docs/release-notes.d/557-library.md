- Tests › Library now lists check groups, profiles and scenarios, each opening a read-only detail with one editor and one Save. It opens on Profiles and then on the tab last used in the project.
- Check groups are edited one check at a time in a sheet for each of the sixteen check types, with names, explicit conditions and plain choices such as Equal or Different. A check the release cannot evaluate stays listed as Unsupported and is never dropped. Use in test links a group to a test at its exact version.
- Profiles show their segments and fields with each field's presence, type, repetitions, codes, authority, date handling and origin. Editing a field saves the whole profile as a new version. History compares versions, Affected tests upgrades chosen tests' pins after showing what changed, and Metadata packs shows each pack's support matrix. Edit JSON, Import profile and Export profile are in the profile's menu; importing a package also records its metadata pack.
- Scenarios are created from a family and template, edited as ordered events, previewed in memory as synthetic messages for their saved seed and base time, and turned into one synthetic case with Create case. The case records which scenario version it came from.
- Tools › Sample data holds the SIU fixture, which listens only on a loopback address and is recorded as synthetic, Synthetic families (`readmit synth`), the Scenario library check (`readmit scenario check-library`) and the Demo report.
- The earlier assertion-set, profile and scenario panels are removed; the command line is unchanged.
