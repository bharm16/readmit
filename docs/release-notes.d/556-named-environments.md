- Environments is now a list of the project's named environments, opening to
  one environment's Connection, Observation and Reset values with an Edit sheet
  for each and one Save (#556). Add environment asks for a name, address,
  classification (Not classified by default) and transport, which you choose;
  TLS settings appear only for TLS. Test connection is explicit, says it sends
  no messages and shows a dated result rather than a lasting Connected state.
  Credentials lists references by name, purpose, store and rotation, never a
  secret value or argument; arguments are replaced only when you ask. Allowed
  destinations, Check destination, Duplicate and Remove are in the
  environment's menu. An observation shows its source, completion rule and
  actual collections, where an incomplete collection says why instead of zero
  records; Collect, Reset and Scan configured files show exactly what will run
  before you confirm.
