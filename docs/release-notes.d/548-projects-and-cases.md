- Projects lists the projects you opened, newest first, each opened by its
  row; a moved project stays listed with Locate, and its menu holds Project
  settings, Show in Finder and Remove from recents. New project asks only for
  a name and opens its empty Cases, in the folder you last chose. Unsaved
  editor work waits in one Drafts to restore item (#548).
- Cases is one table — Case, Status, Owner, Updated — with search and filters
  that save nothing and show as removable chips; a row opens Messages, and
  Back returns to the list with that case selected. Observations moved to
  Environments and the demo's guided steps to Tools › Sample data (#548).
- A case's details — name, status, owner, tags, interface revision and
  incidents — and a project's settings — name, owner, tags and named
  interface revisions — are each saved whole with one Save; a stale edit is
  refused with the draft kept and a double click saves once. Saving an
  unregistered case registers it, a rename never changes the evidence, and a
  revision cases still use is never removed without reassigning them (#548).
- A case can be removed from its project while its files stay where they
  are, and a project can be removed from recents without touching it (#548).
- Cases gain notes and attachments: an attachment is copied into the
  project's own storage and is never opened or run, and removing one removes
  only its association with the case (#548).
- Show in Finder (Show in folder elsewhere) reveals a project, case or
  attachment where it is, and Locate asks for a moved project or case and
  records it only once the chosen folder is that object (#548).
