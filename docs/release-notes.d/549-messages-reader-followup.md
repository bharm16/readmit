- Messages names each source by its declared name — from a capture session, a recipe import, or one you give it in the case's Edit details — and otherwise by its exact ID; filters still select the exact source. Metadata search finds a source by its name too. The Filter sheet's Message field rule picks from the fields the case's messages actually hold, and a field can have one "is" and one "is not" rule. The "could not be matched" and "not decoded" counts open exactly those messages as a removable filter. Raw shows the whole message as escaped original text with the selected field marked, a window at a time, including an undecoded occurrence. The reader names the message's direction, Columns chooses whether Kind and Direction show, Search settings appears only when the case's own index has expired or cannot answer, and Create variant starts the reproducer from exactly the checked messages.
