- Findings shows each finding's severity (Error, Warning or Info, declared per
  rule) in a Severity column, lists the most severe first, and the filter can
  choose severities and every rule of the analysis's ruleset (#551). Severity
  is display only: diagnosis reports and `readmit diagnose` output are
  unchanged. The selected finding names each evidence field by its label and
  path and lists the messages its evidence is in, including ones the message
  list has not loaded. View messages selects the evidence field in the
  inspector. When no profile supports the case, Analyze says so and Choose
  profile shows why each was refused; the Analyze sheet names the case version
  it analyzes. Review asks for a reviewer name only when this computer has
  none and saves it on this computer. Analysis settings can be imported from
  and exported to files, and imported settings for a profile this release
  does not run can be kept under a name unchanged. An analysis run under saved
  settings is named by them. A saved comparison of similar findings is named,
  listed in History and reopens from there, and each group lists its member
  cases, each opening on exactly the messages of its evidence.
