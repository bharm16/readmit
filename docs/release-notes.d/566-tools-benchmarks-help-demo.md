- Tools is three rows — Inspect file, Sample data and Benchmarks. Benchmarks
  lists what each scan actually measured in the open project, newest first:
  records, bytes read, duration, throughput and the scanner's peak buffer, with a stopped
  scan shown as Incomplete and no whole-file figures. Generate input writes a
  named, reproducible synthetic input into the project without importing or
  sending anything; Start benchmark scans it or a chosen file under the
  scanner's documented limits. Help lists five task articles with their steps
  and a button that starts each task, searches the articles bundled with this
  version offline, and shows Diagnostics on demand. Try demo opens a synthetic
  demo project kept in the application's own storage, with six steps each done
  in its ordinary screen against the built-in loopback receiver; the demo's
  practice runs are listed in Runs and compare like any other runs.
