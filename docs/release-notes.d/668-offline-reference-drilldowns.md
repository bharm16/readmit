- The HL7 reader opens bound code tables, data-element identifiers and complete
  source definitions offline. Table search is bounded and paged, preserves the
  selected edition and exposes unavailable, ambiguous or partial source content.
  Back returns to the same original message and field. A column guide explains
  source attributes without guessing omitted values or hiding metadata columns.

  Reference narrative is rendered as text. Browsing starts no network lookup and
  changes no original evidence. Existing catalog versions remain readable;
  controlled HL7 catalog content stays outside release bundles while distribution
  approval remains open.
