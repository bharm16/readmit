- Import is now one flow: choose files, a folder or ZIP archives, drop them on the window, or paste messages, then check the format and preview the messages before importing. An HL7 file whose format is clear goes straight to its preview; otherwise you choose the format, including Mirth Connect 4.5.2 and Open Integration Engine 4.6.0 exports. CSV, JSON, XML and text exports are mapped from their own columns or fields, and you can save a mapping to use again. Import creates the case in the project and opens it on Messages; importing the same thing twice creates one case.
- Capture records from a saved source: a local folder, a transfer program or an MLLP listener. Choose the source and start the capture; Stop finishes it and opens the case, and Cancel capture keeps what arrived without creating a case. Capture history lists every capture, and one that was cancelled or interrupted can be opened read-only.
- A capture keeps recording while you use the rest of the project, and the sidebar shows it is recording. Anything that saves, imports, sends or collects waits until the capture is finished or cancelled, and says which capture it is waiting for.
- An MLLP listener's responder can simulate a delay, a rejection, a malformed acknowledgement, no response or a disconnect for a test receiver on this computer only. A TLS listener takes its private key from one of the project's credentials, and its certificate from a file in the project folder.
- A transfer program source reaches only the destinations the capture's environment approves.
- Pasted messages that no import has used are removed after seven days.
- The separate source registration, responder policy, collection and finalize steps of the previous capture panel are gone; the command line keeps `readmit source`, `readmit collect` and `readmit import --collection`.
