- Storage is easier to recover from (#565). Create backup shows what the
  backup will hold and can be stopped, works with no project open by picking
  the project by name, and offers Show in folder once written. A stopped or
  failed restore shows the unfinished folder it kept, and never opens it.
  Recovery copies list when and why each was kept, open read-only, and Restore
  copy creates a separate project instead of changing the current one. Archive
  asks whether to archive the whole project or one case, and Delete from this
  computer is now in a project's or a case's own menu, names the related work
  and retention, and is refused while a protected transfer package is within
  its retention. Repair search appears only for a case whose search needs it,
  and the staged update review shows the compatibility result, what is staged
  and the work kept.
