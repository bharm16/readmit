- The desktop workbench uses neutral light and dark palettes with soft gray selections, contrasting primary buttons and underlined reference links. System appearance, saved theme preferences, keyboard focus and forced-color support remain available.
- The HL7 reader has larger text and rows, numbered original-message lines, syntax colors, and a separate Path column. Selecting a token opens its exact field or component in the table; table selections highlight the original bytes, including repeated values and PHI-masked messages.
- Parser actions use labeled icons and consolidated project/reference menus. Messages is a plain heading, file identity is under Technical details, and the redundant Original message and Source labels are removed. PHI masking remains directly available.
- Explicit file reopening reads current bytes, while cancelling the chooser preserves the initiating capture and field. Receive setup is immediately visible, and Settings Back returns to the reader.
- Segment disclosure collapses and expands fields. Scalar fields no longer grow duplicate component rows; nested and omitted positions retain their parent, order, depth and source state. Message identity and segment navigation are available on direct selection and restart, and comparison headings identify both selected messages.
- PHI masking preserves the current reference view and tab and remains enabled when that reader session is restored. Sticky grid headers stay above the Path cells while scrolling.
