Download and install

Release status: unsigned development preview. The only published archives are the v0.1.0-alpha.2 GitHub prerelease, built from an early commit that shipped readmit inspect alone. Everything else on this site is on main and has not been published as an archive yet. Nothing is code-signed or notarized; an operating-system or endpoint policy may refuse to run it.

Published prerelease archives

Archives, checksums.txt and build provenance are published only on GitHub Releases. Each archive holds one static executable with no runtime, installer or container requirement, plus the README, the documentation pages, third-party notices and licenses, the field-label source, and synthetic fixtures.

VERSION is the release tag without its leading v, so the current prerelease is readmit_0.1.0-alpha.2_darwin_arm64.tar.gz. The floors follow Go's supported platforms. CI runs the exact archives on the current runner for each target; it does not certify every older release in the range. There is no Windows arm64 archive and no desktop installer.

Check before you extract

shasum -a 256 readmit_0.1.0-alpha.2_darwin_arm64.tar.gz   # macOS
sha256sum readmit_0.1.0-alpha.2_linux_amd64.tar.gz        # Linux
Get-FileHash .\readmit_0.1.0-alpha.2_windows_amd64.zip -Algorithm SHA256   # Windows
# compare with the matching line of checksums.txt, then extract and run:
tar -xzf readmit_0.1.0-alpha.2_darwin_arm64.tar.gz
./readmit inspect testdata/fixtures/adt-cr.hl7

GitHub build provenance is attested for each published executable and is separate from OS code signing. With the GitHub CLI: gh attestation verify ./readmit --repo bharm16/readmit (or readmit.exe).

Build the current branch

To evaluate the workflows on this site before the next tagged prerelease, build from source with the pinned Go 1.27.1 toolchain. The build is static, needs no C compiler, and produces one file.

git clone https://github.com/bharm16/readmit
cd readmit
go build -trimpath -o readmit ./cmd/readmit
./readmit --help
sh samples/synthetic-walkthrough/walkthrough.sh

What CI checks on every push, so you can read its verdict instead of taking this page's word for it: the race-enabled Go suite, an independently implemented HL7 endpoint against an externally authored corpus, mutation checks, fuzz shards, a vulnerability scan, packaging of the five archives, and a native run of each archived executable with an empty PATH. The workflow is ci.yml; the local loop is in the README.

Desktop shell

The desktop shell is a separate module over the same engine. It is compiled and vetted in CI on macOS only, is not in any archive, and has no installer. Building it needs the Wails 2 toolchain, Node 24 and a platform webview; the procedure is in the README.

What installation does not include

  • No installer, service, daemon, scheduled task, shell integration or PATH change. You extract a directory and run a file.
  • No update check. A newer version is a new archive you choose to download.
  • No account, activation or entitlement. Every workflow here runs without one. readmit license verifies an offline entitlement file when an organization has been issued one; none is required to evaluate.
  • No telemetry, crash reporting or analytics, and this site carries none either.

Upgrading and removing

Evidence directories are versioned strict-JSON files and raw payloads that a newer executable reads through explicit contract versions; a version it does not read is refused, never migrated in place. To upgrade, extract the new archive beside or over the old executable. To remove readmit, delete the directory; it wrote nothing anywhere else except the evidence and documents you asked it to write, and the desktop shell's three named local documents described in the desktop contract.
