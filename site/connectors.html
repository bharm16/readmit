Observation sources and connectors

readmit gets evidence from a small number of places, each one declared in a versioned document an operator selects explicitly. This page lists every source the current branch reads, and names the ones it does not, so that no connector has to be inferred from silence. "Implemented" means a documentation page describes it and a test exercises it; see CLAIMS.md.

Implemented

SourceStatusHow it is reachedDocumentation
HL7 files, raw or MLLPImplementedOne raw message per file with CR, LF or CRLF endings, or one or more MLLP frames. Mixed endings, batch wrappers and concatenated raw messages are rejected rather than repaired.README
Folders and ZIP archivesImplementedimport under a declared plan: framing, boundary, terminator, encoding, direction and membership each a flag with no default. Absolute, traversing, linked or repeated archive entries are refused before they are read.import
CSV, JSON, XML and timestamped text envelopesImplementedimport --recipe: a strict-JSON recipe names one typed operator for each of payload, observed time, source, direction and channel. CSV is read byte-exactly; XML character data from the member's own bytes.mapping
A directory this machine can already openImplementedreadmit-source/v1 kind directory: a local export folder, a mounted share, a tree another tool synced. One directory's own entries; no recursion.source
A remote export through your own transfer programImplementedKind transfer: readmit runs the read-only program you declare, with a two-verb list / get contract, and gives it a credential reference on standard input. This is how an SFTP export is collected. readmit implements no SSH or SFTP client and cannot establish what answered.source
File export as an observationImplementedobserve collect over a readmit-observation-source/v1 or /v2 declaring a bounded JSON, CSV, XML or text export and the locator of the record key. An export older than the declared bound is stale evidence.observe
Approved HTTPS API as an observationImplementedGET only, no redirect followed, no proxy from the environment, TLS 1.2 floor with verification always on, destination checked by the same send policy a replay is held to, credential by reference. A response stating neither Age nor Date is ambiguous, not current.observe
Downstream HL7 capture as an observationImplementedreadmit-observation-source/v2 kind downstream-capture: collect retains what the downstream system was sent, and the observation reads that sealed case under one shared field selector naming the position its record key sits at. Nothing is asked of the system under test — no acknowledgement receipt and no ledger export — and the capture is opened through the verifying case reader and never written to.observe
Inbound MLLP: plain, TLS, mutual TLSImplementedcollect binds loopback unless --approved-bind; declaring a client CA requires and verifies a client certificate it issued; the private key is a credential reference. listen is the SIU fixture receiver.collect, listen
Outbound MLLP to a recorded test environmentImplementedreplay, test --send and target check resolve the address at the point of sending and deny what no policy names. test sends to literal loopback only. This release's MLLP transport presents no client certificate.replay, target

Not available

SourceStatusWhere it stands
PostgreSQL, SQL Server, OracleNot availableDatabase observation is selected in decision D3 with named drivers and test targets. The drivers are not installed and no command reads a database. Canonical evidence is a directory, never a database.
Mirth Connect and Open Integration Engine exportsNot availableAdapters for Mirth 4.5.2 and OIE 4.6.0 are selected in decision D2. No engine export format is implemented, named or assumed. A generic CSV, JSON, XML or text envelope from any tool can still be mapped with import --recipe, which makes no claim about the engine that wrote it.
SSH or SFTP inside readmitNot availableBy decision: Cobra stays the released executable's only direct dependency. Use your own client through a transfer source.
Scheduling, polling daemons, watching a folderNot availableBy design. Every collection and observation is one foreground run with cancellation.
Plain HTTP, any method but GET, writing to any sourceNot availableBy design. readmit serves nothing over HTTP and never writes to, acknowledges or marks anything at a source.

What every source has in common

  • A source is declared in a strict-JSON document with a version; unknown members are errors, and an omitted quota is an error rather than a likely value.
  • A collection or observation that could not run is an execution error, never evidence that nothing was there.
  • Credentials are references to a store readmit never writes to, resolved by running the program you declared, scoped to one purpose and one endpoint.
  • A remote destination is checked by one send-policy rule before it is reached, and the decision is retained.
  • Original bytes are retained unchanged beside whatever readmit derived from them.
